Arquitectura del modelo
Ensemble: XGBoost + Random Forest + Ridge Regression
El modelo combina tres algoritmos en un stacking ensemble. XGBoost captura relaciones no lineales complejas entre variables meteorológicas. Random Forest reduce la varianza y maneja valores atípicos. Ridge Regression actúa como meta-learner para combinar predicciones con mínimo sobreajuste.
