Arquitectura del modelo
XGBoost (Gradient Boosting)
XGBoost captura relaciones no lineales entre las variables del sensor (temperatura, humedad, presión) y el ciclo horario del día. La arquitectura se eligió por validación cruzada temporal comparando contra un stacking ensemble (XGB + RF + Ridge) y el baseline naive de persistencia: con 381 horas de datos reales, XGBoost solo obtuvo el menor RMSE.
